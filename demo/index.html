How this would work

Sourcing
The Sourcing agent reads new partner applications each night, saves each community once and scores it on activity, size and niche fit.
Outreach
The Outreach agent drafts a short, personal first message for every new owner, and a person approves it before anything goes out.
Onboarding
When an owner signs, the Onboarding agent prepares their welcome kit and a 7-day challenge kit for their members.
Milestones and rewards
The Milestones agent recounts referrals every night and flags partners who reach 10 referrals a month for a reward.
Sponsorships
The Sponsorships agent ranks signed partners for paid collaborations using their fit score and referral results.
Slack community
The Slack agent answers common partner questions in a private Slack and passes anything tricky to a person.
Agents do the work. A person approves anything that goes out.
